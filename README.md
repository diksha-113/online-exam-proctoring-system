# Online Exam Proctoring System

## Overview
A web-based online examination system with automated proctoring features to monitor students and detect suspicious activities during exams.

## Features
- Real-time webcam monitoring
- Background noise detection
- Copy-paste and tab-switching detection
- Role-based login system (Student/Admin/professor)

## Tech Stack
Python, OpenCV, HTML, CSS, JavaScript
